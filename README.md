# Super Nonomura Bros

GitHub Pages にそのまま置ける、スマホ中心のオリジナル横スクロールゲームです。

## 遊び方

- PC: `←` `→` または `A` `D` で移動、`↑` `W` `Space` でジャンプ
- スマホ: 画面左下の `◀` `▶`、右下の `JUMP` ボタンで操作
- コインを集めながら、右端の `GOAL` まで進むとクリア
- 敵は上から踏むと倒せます。横から触れるとライフが減ります。

## 操作キャラ画像の差し替え

あとから好きな画像に変える方法は2つあります。

1. 画面開始前の「操作キャラ画像を選ぶ」から画像を選ぶ。
2. リポジトリに `assets/images/player/player_icon.png` を追加する。

`player_icon.png` を置いた場合、ページ読み込み時に自動でその画像が使われます。
正方形のPNG画像にすると、スマホでも見やすいアイコン型になります。

## GitHub Pages で公開する手順

1. このフォルダの中身をGitHubリポジトリにアップロードする。
2. GitHubの `Settings` → `Pages` を開く。
3. `Deploy from a branch` を選び、`main` ブランチの `/root` を指定する。
4. 表示されたURLを開く。

## 注意

このコースは公開しやすいように、既存ゲームのステージをそのまま再現したものではなく、オリジナルの横スクロールコースとして作っています。
